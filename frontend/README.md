# Projeto Ótica - Display de Produtos

## 📖 Descrição
Sistema de display de produtos para ótica desenvolvido em React + TypeScript + Tailwind CSS + PostgreSQL.

## 🚀 Tecnologias

# Backend
- PostgreSQL
- Node
- Express

# Frontend
- React + Vite
- TypeScript
- Tailwind CSS


## 📦 Instalação
```bash
npm install
npm run dev
